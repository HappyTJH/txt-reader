# Security Policy

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory
for this repository if available, or by contacting the maintainers before
publishing details publicly.

Include:

- A clear description of the issue
- Steps to reproduce
- Affected browsers or environments
- Any proof-of-concept files needed to verify the report

## Scope

TXT Reader is a browser-only static app. The most important security and privacy
expectations are:

- Uploaded text files should remain local to the browser.
- Saved books and progress should stay in browser storage.
- Dependencies and GitHub Actions should remain reasonably up to date.
